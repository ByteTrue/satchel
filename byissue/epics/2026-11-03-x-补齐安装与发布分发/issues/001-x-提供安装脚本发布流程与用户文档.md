# 提供安装脚本、release workflow 与用户文档

## 范围

新增 Unix/PowerShell 安装器、版本化 release workflow、安装/升级/卸载文档。安装器必须检测平台、下载归档和校验和、验证后安装；支持版本和目录覆盖，不擅自修改 profile/PATH。公开仓库的一键安装与未发布版本的边界写清楚，不创建 release/tag。

## 验证

- 用本地 release 资产和自定义目录实际运行 install.sh：校验成功、版本正确、校验和损坏会拒绝。
- shell 静态语法检查；PowerShell 若本机无 pwsh，明确标为未执行，只做代码审查与 CI 语法检查可行项。
- release workflow 只监听 v*，权限最小化，不自动跑在未授权 tag。
- README 命令可复制；公开仓库可匿名获取脚本，尚无 release 时不虚称 latest 已可下载。
- 全量 Go/Skill 检查不回归。

## 执行记录

已新增：

- `scripts/install.sh`：Darwin/Linux amd64/arm64、latest/tag 解析、版本/目录覆盖、SHA-256、原子替换、版本自检与 PATH 指引。
- `scripts/install.ps1`：Windows amd64/arm64、latest/tag、SHA-256、默认 LocalAppData 安装、失败清理与 PATH 指引。
- `scripts/test-installer.sh`：本地 release 资产成功安装和损坏校验和拒绝。
- CI 在 Ubuntu/macOS/Windows 用同一批 artifact 运行安装器；`release.yml` 仅在 `v*` tag 运行测试、构建并上传资产。
- README 安装/指定版本/目录/首次配置/升级/卸载；仓库已按用户授权改为 public。

验证：

- `shellcheck`、`actionlint` 通过。
- macOS arm64 本地 file release 实际安装成功，`satchel dev` 可执行；损坏 SHA256SUMS 明确拒绝且不落 binary。
- 非法 tag `../bad` 在下载前拒绝。
- 本机无 pwsh，Windows 安装器尚未本机执行；已配置 Windows CI 实测，待 workflow 实际运行后再声明。
- 未创建 release 或 tag，latest 尚无真实 release 可供下载。

独立 review 为 OK with notes，随后已修完其四项发现：Windows PATH 指引改用原 User PATH 并转义 apostrophe；Windows CI 改用 PowerShell 5.1；新增 Windows 损坏校验和拒绝；测试脚本精确断言 dev/ci/tag 版本。修复后 shellcheck/actionlint/test-installer 与 git diff --check 通过，最终独立复核 **PASS / No issues found**。Issue 保持 open，关闭需用户明确授权。

## 关闭结论

Unix/Windows 安装脚本、校验和拒绝、CI 三平台安装验证、`release.yml` 与 README 安装指南已交付并通过独立复核。长期分发边界已合回 Project Spec，经用户授权关闭。
