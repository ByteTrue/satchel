把 Epic 前五项能力收束成可重复构建、可核验、可分发的一版 Satchel；不创建远端 release 或推送 tag，除非用户另行明确授权。

本 issue 包含：

- 纯 Go 六目标构建：darwin/linux/windows × amd64/arm64，Windows `.exe`。
- 可注入版本号、SHA-256 校验和、发布归档与必要第三方 notice。

## 质量承诺

- `CGO_ENABLED=0`，各目标不需要 C 工具链或外部运行时；构建产物名和校验和可复现地生成。
- 发布包包含代码实际需要的 Magpie/依赖 notice；不能只有源仓库有而分发物缺失。
- 版本注入不改变默认开发版本；tag/release 由用户显式决定。
- README 的支持矩阵只列代码已实现的协议，实测/fixture/未验证状态分开。
