# 实现四协议主动识图

## 目标与范围

实现用户配置固定模型、Agent 主动调用的 `image_ask(paths, question)`，不恢复 Pi hooks 或自动附件分析。

本 issue 包含：

- 四种非流式协议：OpenAI Completions、OpenAI Responses、Anthropic Messages、Google Generative AI。
- 1–4 张本地绝对路径图片、总计 20 MiB、PNG/JPEG/GIF/WebP 魔数校验、顺序保持。
- 可选 question；缺省完整描述并转录可见文字；返回模型文本。
- `vision` 配置区域、凭据/env/headers、脱敏、setup 与独立 `image_ask` 开关。
- MCP schema、直接调用拦截、stdio 与 Pi 主链路。
- 从 Magpie 协议转换与现有 pi-vision 行为提取请求/响应契约，保留超时、响应限制、错误脱敏和禁止重定向。

不包含：Vertex、Bedrock、Codex 登录、Pi Messages、任意 custom API、远程图片/base64 工具参数、自动附件钩子、模型发现、streaming/完整聊天能力。

## 必须修改 / 需要验证 / 仍未知

- 必须修改：独立 vision 包、vision 配置、MCP/CLI/setup、README、协议与集成测试。
- 需要验证：001/002 的生图、搜索、抓取不回归；图片顺序与总预算；Agent 不能选择模型；关闭后不可执行。
- 仍未知：四种 Responses/Anthropic 非流式响应变体的最小解析面；以现有实现和 fake fixtures 锁定，不搬完整 IR。

## 质量承诺

- 主模型无需视觉能力即可得到文本描述；调用使用用户配置的 provider/model，不能由 Agent 改路由。
- 本地图片读取有明确数量、总字节、类型和 regular-file 校验；不把路径或图片发往配置之外的 endpoint。
- Provider 请求禁止自动重定向，API key/custom headers 不得跨 origin；错误不泄露密钥。
- 单调用在 Pi 默认请求预算内返回或报错；响应有大小限制，context 取消向上游传播。
- 默认测试不需要真实 key；只有 OpenAI Completions 可做当前 fake/live 主链路，其余协议只声明 fixture 覆盖。

## 风险与穿刺顺序

| 顺序 | 风险 | 怎样算打通 |
| --- | --- | --- |
| 1 | 四协议图片内容形状与响应解析不一致 | 四组 `httptest` golden tests 验证 URL、payload、图片顺序、认证和文本解析 |
| 2 | 总图片预算与类型校验被绕过 | 第五张、累计超限、相对路径、非 regular、伪造 MIME 均失败且不发请求 |
| 3 | 凭据沿 redirect 泄漏 | 跨 origin 测试确认目标无请求、错误无 secret |
| 4 | MCP 开关或 Pi 集成只停留在内部测试 | 真实 stdio/Pi 使用 tiny PNG + fake OpenAI Completions 得到描述，关闭项不可调用 |
