# 实现视频生成与统一任务查询

## 目标与范围

实现 Magpie 对齐的 `generate_video(prompt,seconds,size,image,reference_images,path)`，并与图片共享 `generation_result(id)` 和模块开关。

- `video` 配置区域：固定 provider/model，setup 可配置；Agent 不传模型。
- OpenAI-shaped Videos API 与 Ark content-generation tasks；创建、轮询、完成/失败、取消和超时。
- 首帧与参考图按协议传递；不支持的输入明确拒绝。
- 视频 URL 使用 SSRF-safe 下载，单文件 512 MiB；MP4 独占创建、自动编号、相对/绝对 path。
- 20 秒未完返回任务 id，后台继续；generation_result 获取图片或视频结果。

不包含订阅型 Grok/Codex、完整 Magpie 账号/插件体系。无视频配置时给出 setup 错误，不隐藏工具。

## 质量与验证

`httptest` 覆盖创建/轮询/错误/取消/SSRF/大小限制；真实 stdio 慢任务→id→MP4；Pi 工具列表和 fake-provider 实测。真实视频 provider 未运行时只声明 fixture 覆盖。

## 执行记录

已实现 `internal/video`：OpenAI-shaped Videos 与 Ark content-generation tasks；创建/轮询/终态/失败/取消、首帧与参考图、秒数/尺寸、同 provider content 下载、SSRF-safe 公网下载、512 MiB、MP4 独占创建和失败清理。

CLI 增加 video 配置与 setup（API/baseURL/key/model/outputDir），Image 模块统一开关；path 与图片共用 GenerationTarget，单次视频总预算 10 分钟，20 秒后由同一任务管理器返回 id。

验证：协议 golden、轮询/取消/大小/SSRF/签名 URL/文件安全、全量 Go test/vet/race 全绿。`TestSatchelStdioSlowVideoGenerationResult` 通过真实二进制完成 22 秒慢 create→pending id→generation_result→MP4，三个 Image 业务工具正确暴露。创建后取消/超时还会用独立 5 秒上下文 best-effort DELETE OpenAI/Ark 远端任务；data URL 强制图片魔数，Ark 比例就近映射，path EEXIST 重试编号，均有回归。真实 Pi 在未配置视频时调用 generate_video，返回 `video is not configured; run 'satchel setup'`，无重试或错误路由。未配置真实视频 provider，能力本身只声明 fixture/stdio 覆盖。独立 review 曾为 PASS with notes；随后补齐 `TestGenerateDeadlineAlsoCancelsProviderTask` 和确定性 `TestGenerateVideoRetriesEEXISTWithNextNumber`，deadline 与 EEXIST 重试均有直接证据。全量 Go test/vet/race 与六平台构建通过。最终独立复核 **PASS / No issues found**。Issue 保持 open，关闭需用户明确授权。
